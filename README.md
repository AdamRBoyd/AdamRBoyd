## About Me

I'm **Adam Boyd**, a frontend-focused software developer specializing in **React** and modern **JavaScript**. I enjoy building clean, intuitive, and accessible interfaces with strong emphasis on component architecture, usability, and visual polish.

I earned my **B.S. in Computer Science** from **California State University, East Bay**, and have been working professionally in software since **2021**, primarily through freelance and independent development.

Alongside software development, I run **Anvil & Ember Metalworks**, where I design and sell handcrafted jewelry. Running a creative business has sharpened my attention to detail, design sensibility, and user-experience thinking — qualities that directly influence my frontend engineering work.

🚀 **Tech Stack:** JavaScript (ES6+), React, HTML5, CSS3, Git  
🛍️ **Live Project:** https://anvilandembermetalworks.com  
📬 **Seeking:** Full-time Frontend / Software Engineering roles
